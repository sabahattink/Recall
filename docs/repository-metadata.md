## Repository features to enable

- **Issues** — already the primary bug/feature-request channel (see `.github/ISSUE_TEMPLATE/`).
- **Discussions** — for questions and usage help that aren't bug reports, to keep Issues focused on actionable work.
- **Private vulnerability reporting** (Settings → Security → "Private vulnerability reporting") — matches the process already documented in [SECURITY.md](../SECURITY.md).

## Not covered here
