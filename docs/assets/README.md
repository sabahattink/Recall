- **Terminal:** a plain, readable theme (dark or light, high contrast), default font size, window narrow enough to render legibly at README width (~900px).
- **Content:** exactly the commands in `docs/demo-script.md`, run against the small demo repository referenced there — no edited/sped-up output, no fabricated command results.
