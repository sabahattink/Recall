---
title: Installation
description: Run Recall with npx, or install the recall executable once.
---

## Run without installing

```bash
npx recall-context init
```

`npx` downloads the package and runs it once; nothing is installed globally.

<Callout type="warn" title="Use recall-context, not recall">
  The npm package named `recall` is unrelated to this project. Always run `npx recall-context`.
</Callout>

## Install once

```bash
npm install -g recall-context
```

The package installs an executable named `recall`:

```bash
recall init
```

With pnpm, `pnpm add -g recall-context` installs the same executable.

## Requirements

- Node.js 22 or newer.
- Nothing else. No account, no API key, no configuration file.

Recall itself never uses the network. The only network access involved is your package manager
downloading `recall-context`.
