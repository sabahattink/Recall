---
title: Getting started
description: Initialize a repository and connect your AI assistant to its memory.
---

## 1. Initialize the repository

From the root of the repository:

```bash
npx recall-context init
```

To initialize a repository somewhere else, pass its path:

```bash
npx recall-context init ./path/to/repository
```

## 2. Check the output

A successful run prints exactly this, and nothing else:

```text
Scanning repository...
Detecting architecture...
Generating AI memory...
Done.
```

It has written one directory:

```text
.recall/
├── memory.json
└── agents/
    ├── claude.md
    ├── codex.md
    ├── cursor.md
    ├── gemini.md
    └── openai.md
```

Nothing outside `.recall/` was created or changed. `.recall/` is plain text; whether you commit it
is up to you. Recall does not edit `.gitignore` or any other file.

## 3. Connect your assistant

Each file in `.recall/agents/` is written for one assistant. Connect the ones you use:

| Assistant        | File                       | One-time setup                                                                     |
| ---------------- | -------------------------- | ---------------------------------------------------------------------------------- |
| Claude Code      | `.recall/agents/claude.md` | Add `@.recall/agents/claude.md` to `CLAUDE.md`.                                    |
| Codex            | `.recall/agents/codex.md`  | Copy it to `AGENTS.md`, or reference it from your existing `AGENTS.md`.            |
| Cursor           | `.recall/agents/cursor.md` | Copy it to `.cursor/rules/recall.mdc`.                                             |
| Gemini CLI       | `.recall/agents/gemini.md` | Add `@.recall/agents/gemini.md` to `GEMINI.md`.                                    |
| ChatGPT / OpenAI | `.recall/agents/openai.md` | Paste it into a ChatGPT Project's instructions, or use it as an API system prompt. |

For Claude Code, the entire change is one line in `CLAUDE.md`:

```md title="CLAUDE.md"
@.recall/agents/claude.md
```

[Output format](/docs/output-format#using-the-agent-files) has the exact steps for every assistant.

## 4. Regenerate when the repository changes

Running `recall init` again on an initialized repository changes nothing and exits with code `4`.
To regenerate the memory from the current state of the repository, pass `--force`:

```bash
npx recall-context init --force
```
