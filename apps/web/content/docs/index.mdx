---
title: Introduction
description: Recall initializes a repository's memory for AI coding assistants.
---

Every AI coding assistant starts a new session knowing nothing about your repository. Recall
removes that gap once: one command reads the repository and writes `.recall/`, a project memory
that Claude Code, Codex, Cursor, Gemini CLI, and ChatGPT can read instead of asking you.

```bash
npx recall-context init
```

```text
Scanning repository...
Detecting architecture...
Generating AI memory...
Done.
```

The npm package is `recall-context`; the executable it installs is `recall`.

## What you get

```text
.recall/
├── memory.json
└── agents/
    ├── claude.md
    ├── codex.md
    ├── cursor.md
    ├── gemini.md
    └── openai.md
```

- **`memory.json`** is the Project Memory: the single source of truth about the repository. Every
  entry carries `evidence`, the file it was derived from and why.
- **`agents/*.md`** are five read-only renderings of `memory.json`, one per assistant, each in the
  format that assistant reads.

Nothing else is written, and nothing outside `.recall/` is touched. See
[Output format](/docs/output-format) for both files in detail.

## What Recall does, and doesn't

- It **reads** your repository. It never runs your code, tests, build, or scripts.
- It works **offline**. No account, no API key, no telemetry, no LLM calls.
- It is **deterministic**. The same repository state produces byte-identical output on any machine.
- It is **not** an assistant, a chat interface, or a platform. It produces the memory assistants
  read; it does not talk to them or for them.

| Area             | Recognized                                                                                                                          |
| ---------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Languages        | TypeScript, JavaScript, Python, Go, Rust                                                                                            |
| Frameworks       | Next.js, NestJS, React, Express, Fastify, Vue, Angular, Nuxt, Svelte and SvelteKit, Astro, Remix, React Native, Electron, Hono, Koa |
| Package managers | pnpm, npm, Yarn, Bun, pip, Poetry, uv, Pipenv, Go modules, Cargo                                                                    |
